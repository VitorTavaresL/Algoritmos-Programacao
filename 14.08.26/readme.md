# Estudo dos erros em programas,  Algoritmos e Programação - Cibersegurança 2026

## Erro de Sintaxe / Syntax 
### Um Erro que torna impossível analisar o programa - e, portanto, impossível de interpretá-lo.

## Erro em tempo de execução
### Erro que ocorre depois que um programa começou a ser executado, mas impede o programa de continuar.

## Erro de Semântica / *Erro de lógica*
### Erro que faz o programa fazer algo diferente do oque o programador pretendia.
